# Sidequest Website

Static marketing and support website for the Sidequest iPhone app.

App Store link: https://apps.apple.com/sk/app/sideq/id6767996805

## App Store URLs

- Marketing URL: `https://sidequest-ios.netlify.app/`
- Support URL: `https://sidequest-ios.netlify.app/support.html`
- Privacy Policy URL: `https://sidequest-ios.netlify.app/privacy.html`

## SEO Files

- `robots.txt` allows indexing and points crawlers to the sitemap.
- `sitemap.xml` lists the marketing, support, and privacy pages.
- Each HTML page includes canonical, Open Graph, Twitter, and structured data metadata.
